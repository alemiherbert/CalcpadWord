# Ribbon and shortcuts

| Button | Shortcut | Does |
|---|---|---|
| Calculate | Ctrl+Alt+F9 | Calculates everything, headers and footers included |
| Calculate automatically (Calculate ▾) | | On by default; see [Calculating](Calculating.md) |
| Cancel | Esc, while calculating | Stops a background calculation |
| Convert to Calcpad | Alt+Shift+Enter | Selection or paragraph → Calcpad. On a result: shows its source |
| Calcpad Block | | Selected paragraphs, or an empty line → block |
| Block to Text | right-click a block | Block → Word text |
| Edit Source | double-click a result | Shows the source; click outside to calculate |
| Symbols grid, ▲ ▼ ▾ | | Types a symbol at the cursor |
| Errors (n) | | Lists errors; pick one to go to it |
| Next Error | Ctrl+Alt+F8 | Next error, message in the status bar |
| Lock, Unlock | | Locks expressions and blocks in the selection against edits; inputs stay open |
| Decimals, Angles, Substitute values | | How results are written |
| Math font, Plain Word math | | How equations look |
| Complex numbers | | Calcpad's complex mode (off by default) |

Settings are saved in the document. KeyTips: Alt, C, P, then the letter.

## Math font

Sets the font of every equation in the document. Offers Asana, Cambria, Euler, Fira, Latin Modern, Libertinus, Noto Sans, STIX Two, TeX Gyre Pagella and XITS Math, plus any other installed math font. Setup installs the free ones; one marked *(not installed)* is reinstalled when chosen.
